Automau5 Privacy Policy

Effective November 14, 2026

Automau5 does not collect, transmit, or share any personal data. It has no accounts, analytics, advertising, or crash reporting, and it makes no network connections.

This policy covers the Automau5 desktop app and the am command-line tool on Windows, macOS, and Linux, including versions distributed through the Microsoft Store and the Mac App Store.

What the app does

Automau5 runs entirely on your device. Depending on the mode you choose, it moves the mouse pointer, clicks, presses keys you've chosen, or asks the operating system not to go to sleep, at an interval you set.

Information stored on your device

The desktop app saves your settings locally so they're remembered next time: the selected mode, interval, repeat count, keep-awake options, and any key combinations you've recorded. This data stays on your device and is never sent anywhere. Uninstalling a Store version removes it; with other installers it may remain in your user profile's app data folder until you delete it.

The activity list shown in the app is kept in memory only and is cleared when the app closes.

Keyboard and input

Automau5 does not monitor or log what you type. It reads a key press only while you're recording a key combination, after clicking Record key, and saves only the name of that key (for example, ctrl+shift+a).

Keys and clicks that Automau5 generates go to whichever window is in focus, just as if you'd pressed them yourself.

System permissions

  • macOS Accessibility: required for the Move, Click, and Type modes, because macOS only lets approved apps generate mouse and keyboard input. Automau5 uses this permission solely to generate the input you configure, never to read the contents of other apps.
  • Keep awake: uses the operating system's standard power-management features and needs no special permission.

Network access

Automau5 does not connect to the internet. It contains no code that sends data off your device, and the desktop app's security policy blocks network requests.

Third parties

Automau5 does not share data with anyone, because it doesn't collect any. App stores and your operating system may collect information under their own policies, for example download statistics or crash data collected by Microsoft or Apple. That collection isn't controlled by Automau5. See the Microsoft Privacy Statement and Apple's Privacy Policy.

Children

Automau5 collects no data from anyone, including children.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date. Significant changes will also be noted in the app's release notes.
